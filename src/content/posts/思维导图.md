# 家里云 AI Dev Agent 平台 — 架构全景思维导图

> 本文档记录了一套基于「家机纯算力 + CF 边缘控制面 + Serv00 备线 + NewAPI 模型网关」的多用户 AI Dev Agent 平台架构设计。

## 架构总览

- ☁️ Cloudflare 边缘层（门面 + 控制面）
  - Pages（前端面板）
    - React/Vue SPA
    - 用户操作界面
    - Diff 展示 / 文件树 / 聊天
  - Worker（API 网关）
    - 鉴权（JWT 验签）
    - 限流（按用户 / 套餐 / 路径）
    - 模型路由决策（免费→DeepSeek / 付费→Codex+Claude）
    - 任务入队（Queue）
    - 安全规则（WAF / 命令黑名单）
    - 凭证代理（签发临时 Token）
  - D1 / KV（数据层）
    - 用户表 / 套餐 / 配额
    - 限流计数 / 黑名单
    - Feature Flag
  - R2（对象存储）
    - Diff 产物
    - 构建日志
    - 任务快照
  - Queue（任务队列）
    - 解耦边缘与执行
    - 任务状态流转
  - Tunnel（内网穿透）
    - 家机零端口暴露公网
    - 加密隧道回源
  - Access（访问控制）
    - 内测用户邮件验证码
    - IP / 国家策略

- 🆓 Serv00 免费机（备线 + 预检）
  - 备用入口
    - CF 挂了时顶上
    - Caddy 反代 → 家机
  - 任务预检（规则层）
    - 提示词扫描（泄密 / 恶意指令）
    - 命令黑名单（rm -rf / curl|sh / chmod 777）
    - 仓库大小 / 文件数超限检查
  - 状态页
    - 系统健康展示
    - 维护公告
  - Webhook 接收
    - GitHub push 事件
    - PR / Issue 触发
  - Waitlist / 文档
    - 着陆页
    - API 文档

- 🏠 家机 32核/16G（纯算力节点）
  - Orchestrator 守护进程（Go 单二进制）
    - 从 Queue 拉任务
    - 创建 / 销毁容器
    - 注入任务上下文（repo / 指令 / 文件列表）
    - 回收 diff + log → 回传 CF R2
    - 超时 / 异常 / 重试处理
  - 虚拟化层
    - Docker + userns remap（起步）
    - gVisor runsc（升级路线）
    - cgroup v2 硬限制
    - tmpfs 可写层（容器死数据蒸发）
    - 网络默认断网 / 白名单出口
  - 沙箱池
    - 每任务一容器
    - 独立 PID / network / mount namespace
    - 资源限制：CPU 0.5-1核 / 内存 512M-1G / 进程 256
    - 运行时间上限 5-15 分钟
    - 零密钥注入（凭证走 Secret Proxy）
    - 跑完即焚

- 🔑 NewAPI（模型网关）
  - 统一接入
    - OpenAI Codex
    - Anthropic Claude
    - DeepSeek
    - GLM / 通义 / 本地模型
  - 负载均衡
    - 多 Key 轮转
    - 失败自动切换
  - 配额控制
    - Per-user / Per-key token 限额
    - 日/月上限
  - Fallback 策略
    - 贵模型超时 → 降级便宜模型
  - 成本统计
    - 每任务 / 每用户花费
  - 部署位置
    - 独立 VPS / 轻量云

- 🛡️ 授权站（身份中枢）
  - 用户体系
    - 注册 / 登录 / OAuth（GitHub / Google）
    - 套餐管理（免费 / 付费 / 团队）
  - JWT 签发
    - Worker / Serv00 / 家机统一验签
  - 凭证保险箱
    - GitHub SSH Key / OAuth Token
    - Cloudflare API Token
    - 各平台 Key 加密存储
    - 下发临时作用域令牌（不暴露原值）
  - 用量统计
    - 任务数 / Token 消耗 / 费用

- 📊 Uptime 监控（全局眼睛）
  - 监控目标
    - 家机 Orchestrator 存活
    - Docker 池容量（容器数 / 内存）
    - NewAPI 可达性 + 延迟
    - CF Worker 异常率
    - 授权站响应时间
    - 磁盘用量（/var/lib/docker）
  - 告警通道
    - Telegram Bot（实时）
    - 邮件（重要事件）
  - 降级预案
    - 家机挂 → Serv00 顶排队
    - NewAPI 挂 → Worker 直连备胎模型
    - CF 挂 → Serv00 直连（降级模式）

- 🔄 任务完整流转（一次 Agent 执行）
  - ① 用户浏览器发指令
  - ② CF Worker 验签 + 限流
  - ③ 授权站确认套餐 + 权限
  - ④ 任务入 Queue
  - ⑤ Serv00 预检（规则层）
  - ⑥ 家机 Orchestrator 拉取任务
  - ⑦ 创建沙箱容器（干净镜像）
  - ⑧ 注入代码 + 指令 → Agent 循环
  - ⑨ Agent 调 NewAPI → LLM 生成 / 改文件 / 跑命令
  - ⑩ 模型自检 Agent 审查行为
  - ⑪ 产出 diff → 回传 R2
  - ⑫ 容器销毁（tmpfs 蒸发）
  - ⑬ Worker 通知用户 → 面板展示结果

- 🛡️ 安全三层防御
  - 规则层（边缘 + Serv00）
    - 命令白名单 / 黑名单
    - 提示词注入检测
    - 速率限制
  - 语义层（家机 LLM Security Agent）
    - 异常行为识别
    - 越权操作预警
    - 数据外传检测
  - 内核层（容器 + 宿主机）
    - seccomp / AppArmor
    - cap_drop ALL
    - no-new-privileges
    - userns remap
    - gVisor（可选）
    - 网络隔离（独立 namespace / 禁 169.254.169.254）

- 📈 演进路线
  - 阶段 1：链路验证（1-2 周）
    - 家机 + CF Worker + NewAPI
    - 单用户 / 单任务跑通
  - 阶段 2：多用户 + 配额（2-4 周）
    - 授权站接入
    - 套餐 / 限流 / 模型路由
    - Serv00 预检上线
  - 阶段 3：体验打磨（1-2 月）
    - 流式输出 SSE
    - Diff 展示 + 接受/拒绝
    - GitHub PR 自动创建
  - 阶段 4：规模化（2-3 月）
    - 多台家机加入算力池
    - Firecracker 替代 Docker
    - 持久化工作区（可选）
  - 阶段 5：商业化
    - 团队版 / 企业版
    - 私有部署 / 专属模型
    - API 开放平台

- 💰 成本预期（月）
  - 家机：¥0（已有）
  - Serv00：¥0（免费）
  - Cloudflare：¥0（免费额度内）
  - NewAPI 部署机：¥30-50/月（轻量 VPS）
  - 模型 API：按用量（DeepSeek 极便宜，Codex 贵）
  - 域名：¥60/年
  - 合计：¥30-100/月 撑 10-50 用户内测

## 总结

> 家机 = 发电站，只管发电。  
> CF = 电网 + 电表 + 营业厅。  
> Serv00 = 备用发电机。  
> NewAPI = 燃料供应商。  
> Uptime = 仪表盘。  
> 各干各的，不抢活。
